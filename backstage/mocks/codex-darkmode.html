Inventário dos elementos (confirme se entendi o que existe hoje):
  • Caixa / card — fundo superfície + 1px de borda. É o "risquinho teal" no escuro hoje.
  • Estados hover / selecionado — hoje teal em Turmas/Conteúdo/Aulas e cinza em Perguntas/Certificados (via um --surface-hover que nunca foi definido e cai no cinza).
  • Botão primário — hoje usa var(--primary) = #14b8a6 (teal claro) direto, ignorando o token escuro que já existe.
  • Botão secundário / ícone — fundo superfície + borda; sobrevivem porque a superfície já é mais clara que a página.
  • Chip — fundo = cor da PÁGINA, só a borda o separa. É o que poderia "sumir" se a borda escurecesse demais; por isso o cinza é mais claro que a superfície.
  • Campo / opções de resposta — borda 2px; opção selecionada hoje é creme no claro e teal no escuro (troca de cor entre modos).
  • Segmentado — botão ativo herda a cor do primário.
