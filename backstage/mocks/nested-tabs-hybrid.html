Hybrid topbar — sub-tabs inside, not below

Main tabs sit in the top row of the topbar (~56px). When the active tab has sub-tabs, a thinner second row (~30px) appears inside the same topbar chassis, aligned with where the main tabs start. Total topbar height: 86px when sub-tabs exist, 56px when they don't. No separate sub-nav row beneath.

Altura do chrome (comparação)

Option A Topbar 64px + sub-nav 44px (linha separada) 108px
Option B Linha única dinâmica (sub-tabs substituem principais) 64px
Option C Topbar 64px + chip row 24px 88px
Hybrid Topbar único 56px + 30px interno (quando aplicável) 86px
Por que isso pode ser o vencedor: mesmo footprint que Option C quando sub-tabs existem (88 vs 86px), mas menos chrome que Option A (86 vs 108px). E quando você está em Aula ou Turmas (sem sub-tabs) cai pra 56px, igualando Option B sem perder os tabs principais de vista. Hierarquia visual fica clara: tabs principais grandes em cima, sub-tabs menores embaixo, todos no mesmo chassi do topbar.

Ponto de atenção: a fileira de 30px é apertada. Sub-tabs ficam em fonte 0.76rem — legível mas próximo do limite. Em mobile pode precisar quebrar pra uma segunda linha (e nesse caso vira o Option A naturalmente).
